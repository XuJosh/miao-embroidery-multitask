# combined_fused_correct 可视化结果逐图解读

> 说明：以下解读中的“模型认为”“模型关注”均指基于 Grad-CAM / DINOv2 attention 的可解释性分析，不等同于人工标注的缺陷位置。

## sample_047_test_00047_a0（auth=1, pattern=2, defect=1）

**原图**：一幅多层花鸟纹样的红色调苗绣，整体构图饱满。

### Grad-CAM 解读
- **auth（class=1，真品）**：热力图集中在左下角和中间偏下区域，说明模型主要从底部纹样细节判断其为真品。
- **pattern（class=2）**：红色高亮出现在两朵主要花卉图案上，说明模型把这两处花卉结构作为区分 pattern=2 的关键依据。
- **defect（class=1，有缺陷）**：热力图明显集中在中间偏右的一片区域，与 auth/pattern 的关注点不同，说明模型在该位置发现了异常特征，认为可能是缺陷区域。

### DINOv2 attention 解读
- CLS token 最关注左上方和中间偏下的两处图案。
- Overlay 显示这两处正好是绣品中纹样最复杂的区域，说明 Transformer 自动把语义重心放在了主要图案上。

## sample_066_test_00066_a0（auth=0, pattern=1, defect=0）

**原图**：深色底、中心有圆形团纹的绣片，对角有黑色条纹。该样本被模型判为仿品（auth=0）。

### Grad-CAM 解读
- **auth（class=0，仿品）**：热力图高度集中在中心圆形团纹以及底部区域。模型判断为仿品时，最看重的是中心团纹的规整度或纹理细节，可能认为其过于规则、缺乏手工绣品的自然变化。
- **pattern（class=1）**：同样关注中心圆形团纹，说明该团纹是 pattern=1 的核心识别特征。
- **defect（class=0，无缺陷）**：热力图也集中在中心团纹，说明模型通过检查主体图案区域未发现明显瑕疵。

### DINOv2 attention 解读
- CLS token 主要关注中心圆形团纹和右侧对角条纹。
- 这与 Grad-CAM 一致，表明模型对这幅绣品的核心判断都依赖于中心团纹区域。

## sample_320_test_00320_a0（auth=1, pattern=0, defect=0）

**原图**：绿色底、粉色花朵纹样的绣片，构图简洁，主体是几朵大型花卉。

### Grad-CAM 解读
- **auth（class=1，真品）**：热力图集中在左上方最大的那朵粉色花上，说明模型把这朵花作为判断真品的关键。
- **pattern（class=0）**：关注右侧花朵和花蕊区域，不同花朵对应不同 pattern 的判别依据。
- **defect（class=0，无缺陷）**：同时关注左上方和右侧花朵，说明模型在检查这些主要区域后没有发现异常。

### DINOv2 attention 解读
- CLS token 关注中间偏下的花朵以及右下角边缘区域。
- 与 Grad-CAM 略有差异：CNN 更关注左上角花朵，而 Transformer 更关注中间花朵，说明两个分支捕捉到了互补信息。

## sample_324_test_00324_a0（auth=1, pattern=2, defect=0）

**原图**：红色调、人物与动物纹样密集的绣片，画面中有多个小人、动物和装饰图案。

### Grad-CAM 解读
- **auth（class=1，真品）**：热力图分布较广，覆盖了上方动物、中间人物和下方图案，说明真品判断综合了多个人物/动物纹样特征。
- **pattern（class=2）**：重点关注下方举手人物以及上方动物轮廓，这两处是 pattern=2 的判别依据。
- **defect（class=0，无缺陷）**：同样关注人物区域，但热力分布较均匀，未见明显局部异常聚集。

### DINOv2 attention 解读
- CLS token 关注多个分散的小区域：上方动物、中间横向条纹、下方人物。
- 这与 Grad-CAM 的“多区域综合判断”一致，说明 Transformer 也采用了全局-局部结合的注意力策略。

## sample_515_test_00515_a0（auth=1, pattern=0, defect=1）

**原图**：黑色底、蓝绿色竖条和粉色小花交替排列的绣片，整体呈条带状构图。

### Grad-CAM 解读
- **auth（class=1，真品）**：热力图整体较弱，主要集中在上部边缘，说明模型对这幅图的真伪判断依据不太明确，可能更多依赖全局纹理。
- **pattern（class=0）**：强烈关注中间偏右的蓝绿色竖条区域，说明该竖条纹样是 pattern=0 的关键特征。
- **defect（class=1，有缺陷）**：热力图集中在右下角和中间偏下位置，模型认为这些区域存在异常。

### DINOv2 attention 解读
- CLS token 关注左侧蓝绿色竖条和中间偏下的圆形区域。
- Overlay 显示注意力与绣品的主要结构条纹对齐，说明 Transformer 捕捉到了条带状的构图特征。

## sample_560_test_00560_a0（auth=0, pattern=4, defect=0）

**原图**：浅色底、中心有大椭圆形团纹的绣片，纹样风格与 sample_066 类似，但被模型判为仿品（auth=0）。

### Grad-CAM 解读
- **auth（class=0，仿品）**：热力图集中在底部区域和上方局部，模型判断为仿品时关注的是这些局部纹理或边缘特征。
- **pattern（class=4）**：高度关注中心椭圆形团纹，说明该团纹是 pattern=4 的代表性特征。
- **defect（class=0，无缺陷）**：同样集中在中心团纹，说明模型在中心区域未检测到缺陷。

### DINOv2 attention 解读
- CLS token 关注右上角和中心上方的小图案。
- 与 Grad-CAM 的“中心团纹”不同，Transformer 更关注边缘和角落区域，可能反映了对全局布局或背景纹理的敏感。

---

## 总体观察

1. **Auth 任务**：真品样本的热力图多集中在主体纹样区域；仿品样本则倾向于关注局部规整区域或边缘，可能反映了机器仿制品的纹理规律。
2. **Pattern 任务**：热力图明显集中在最具代表性的纹样结构上，不同 pattern 类别关注不同的图案部件。
3. **Defect 任务**：有缺陷样本的热力图通常出现局部高亮区域；无缺陷样本则更多关注主体图案本身。
4. **DINOv2 attention**：Transformer 的注意力分布相对稀疏、聚焦，常落在主要图案或高对比度区域，与 CNN Grad-CAM 形成互补。
